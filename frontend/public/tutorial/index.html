Turing Audio Processing Engine

Tutorial del lenguaje TAPE

Guía práctica paso a paso para escribir programas capaces de construir patrones musicales, contrapunto polifónico y estructuras de audio mediante una Máquina de Turing Multipista.

01 ¿Qué es TAPE?

TAPE (Turing Audio Processing Engine) es un entorno interactivo web para componer patrones musicales y experimentar con audio mediante un Lenguaje de Dominio Específico (DSL).

El lenguaje utiliza como modelo conceptual una Máquina de Turing Multipista. El programa manipula una matriz de celdas mediante un cabezal de lectura/escritura y utiliza canales de emisión independientes para convertir los valores almacenados en eventos sonoros.

En términos simples: primero puedes escribir datos en una cinta, después recorrerla, leer sus valores y finalmente emitirlos como sonido.

Idea fundamental El cabezal de lectura/escritura y los canales de sonido son conceptos diferentes. El cabezal se desplaza por la matriz; un canal de emisión es utilizado por EMIT para producir sonido.

02 El modelo de ejecución

La memoria principal del programa puede visualizarse como una matriz de 4 filas y 35 columnas.

0 1 2 3 4 ... 34
A 00000...0
B 00000...0
C 00000...0
D 00000...0

Las filas se identifican con A, B, C y D. Las columnas van de 0 a 34.

El cabezal de lectura/escritura siempre ocupa una posición concreta de esta matriz (por defecto inicia en A,0). Las instrucciones WRITE, READ y los movimientos actúan sobre la posición actual de dicho cabezal.

Cabezal de lectura/escritura

Se utiliza para recorrer la matriz y leer o escribir valores. No es un canal de audio.

Canales de emisión

Son creados mediante SPAWN y utilizados por EMIT para producir sonido.

03 Tu primer programa

Empecemos con el programa más pequeño que permite escribir una nota:

tape
WRITE(60)

Esto escribe el valor MIDI 60 en la celda que ocupa actualmente el cabezal de lectura/escritura.

Para escribir varias notas en posiciones consecutivas:

tape
WRITE(60);>>
WRITE(62);>>
WRITE(64)

El resultado conceptual en la fila A es:

[60] [62] [64] [0] [0] ...

Aquí 0 representa silencio.

04 Comentarios y separadores

Comentarios

TAPE utiliza comentarios de una sola línea mediante //. Todo lo que aparezca después de // en esa misma línea es ignorado.

tape
// Esta línea es un comentario
WRITE(60) // Escribe un Do central

Actualmente no existen comentarios multilínea.

Punto y coma

El punto y coma ; es opcional y funciona únicamente como ayuda visual para separar expresiones. El compilador lo ignora.

tape
WRITE(60);>>
WRITE(62)>>

// También es posible escribir varias expresiones en una misma línea:
WRITE(71);v WRITE(72)>>
Consejo Usa ; cuando una línea contenga varias acciones. No cambia la semántica del programa; solo hace que el código sea más fácil de leer.

05 WRITE: escribir en la cinta

La instrucción WRITE(valor) escribe un valor en la celda actualmente ocupada por el cabezal de lectura/escritura.

Valor Significado
0Silencio.
1–127Valores de nota MIDI.
tape
WRITE(60)
WRITE(64)
WRITE(67)

Las tres instrucciones escriben sucesivamente sobre la misma celda, porque el cabezal no se mueve automáticamente. Para escribir en otras posiciones debes moverlo explícitamente.

Importante WRITE no mueve el cabezal. Escribir y desplazarse son dos operaciones independientes.

06 Movimiento del cabezal

TAPE dispone de cuatro operadores de movimiento:

OperadorMovimiento
<<Una celda a la izquierda.
>>Una celda a la derecha.
^Una fila hacia arriba.
vUna fila hacia abajo.

Un movimiento por operador

El operador >> representa un solo paso. No es un operador acumulativo.

tape
WRITE(60);>>       // Mueve una posición a la derecha
WRITE(60);>> >> >> // Desplaza tres posiciones
WRITE(60);>>>>>>   // Forma compacta: seis '>' forman tres operadores '>>'
Regla mental >> es un token; >>>> son dos tokens; >>>>>> son tres tokens.

Límites de la matriz

El cabezal no puede salir de la matriz (filas A a D, columnas 0 a 34). Los movimientos que intentan superar estos límites generan un error de desbordamiento.

07 READ: leer la celda actual

READ() devuelve el valor almacenado en la celda que actualmente ocupa el cabezal.

tape
WRITE(60)
READ() // Devuelve 60

// Combinado con EMIT y movimiento:
EMIT(READ(), 8, 1);>>

La instrucción EMIT(READ(), 8, 1);>> sigue este orden:

  1. Leer el valor de la celda actual.
  2. Utilizarlo como valor MIDI.
  3. Emitirlo durante 8 ticks en el canal de emisión con ID 1.
  4. Mover el cabezal una posición a la derecha.

08 Canales de emisión y SPAWN

Los canales de emisión de sonido son independientes del cabezal de lectura/escritura. Para crear un canal se utiliza SPAWN(id):

tape
SPAWN(0)
SPAWN(1)

Instrumentos

El ID determina el tipo de oscilador utilizado para producir el sonido. La selección se realiza de forma cíclica mediante módulo 4:

ID mod 4Oscilador
0triangle
1sine
2square
3sawtooth
No confundir SPAWN crea un canal de emisión; no crea ni mueve el cabezal de lectura/escritura.

KILL

KILL(id) elimina un canal de emisión previamente creado, dejándolo no disponible para futuras emisiones.

09 EMIT: producir sonido

EMIT(valor, duracion, canal)

ArgumentoSignificado
valorValor MIDI que se desea emitir (0 para silencio).
duracionDuración expresada en ticks. Un tick corresponde a una fusa.
canalID del canal de emisión creado con SPAWN.

Ejemplo de una melodía

tape
WRITE(60);>>
WRITE(63);>>
WRITE(67);>>
WRITE(72)

SPAWN(1)

JUMP(1==1, #A, 0)
EMIT(READ(), 8, 1);>>
EMIT(READ(), 8, 1);>>
EMIT(READ(), 8, 1);>>
EMIT(READ(), 8, 1);>>

10 JUMP y control de flujo

JUMP permite cambiar la posición del cabezal de lectura/escritura cuando se cumple una condición.

JUMP(condicion, #fila, columna)

Ojo con el símbolo # #A significa "fila A". En cambio, A sin # es el nombre de una variable.

Salto incondicional y condiciones

Una expresión como 1 == 1 siempre es verdadera, lo que permite posicionar el cabezal directamente en una coordenada conocida. Un JUMP se ejecuta una sola vez y no constituye un bucle por sí mismo.

OperadorSignificado
==Igual a
!=Distinto de
<Menor que
>Mayor que
<=Menor o igual que
>=Mayor o igual que
tape
JUMP(1==1, #D, 0)         // Posiciona el cabezal en D,0
JUMP(READ()==74, #A, 2)   // Salta a A,2 si la celda actual vale 74

11 Variables y asignaciones

TAPE permite definir y actualizar variables mediante =:

tape
nota = 60
duracion = 8
WRITE(nota)

A = 60
JUMP(A == 60, #B, 4) // A es variable, #B es referencia a fila B
Nota Actualmente no existe una instrucción RETURN integrada. Las funciones pueden recibir argumentos y ejecutar instrucciones, pero no disponen de un mecanismo de retorno dedicado.

12 Funciones con DEFINE

Las funciones permiten encapsular secuencias de instrucciones y reutilizarlas. Deben estar definidas antes de ser llamadas.

DEFINE nombre(parametros) { ... }

tape
// Función sin argumentos
DEFINE ScaleOne() {
    EMIT(READ(), 4, 1);v
    EMIT(READ(), 4, 1);>>
    EMIT(READ(), 4, 1);^
    EMIT(READ(), 4, 1);>>
}

// Función con parámetros
DEFINE PlayNote(note, duration, channel) {
    WRITE(note)
    EMIT(READ(), duration, channel)
}

ScaleOne()
PlayNote(60, 8, 1)

13 Construir un programa completo

  1. Preparar la cinta escribiendo valores con WRITE.
  2. Crear los canales de sonido necesarios con SPAWN.
  3. Colocar el cabezal en una posición conocida con JUMP.
  4. Leer los valores con READ() y emitirlos con EMIT.
  5. Mover el cabezal para recorrer otras posiciones.
  6. Utilizar funciones para encapsular patrones complejos.
tape
// Preparar una escala
WRITE(60);>>
WRITE(62);>>
WRITE(64);>>
WRITE(65);>>
WRITE(67)

// Crear canal de sonido
SPAWN(1)

// Colocar el cabezal al inicio
JUMP(1==1, #A, 0)

// Reproducir las cinco notas
EMIT(READ(), 8, 1);>>
EMIT(READ(), 8, 1);>>
EMIT(READ(), 8, 1);>>
EMIT(READ(), 8, 1);>>
EMIT(READ(), 8, 1)

14 Ejemplo real: Cancrizans

El siguiente fragmento procede del programa funcional Cancrizans.tape, inspirado en el Canon Cancrizans de J. S. Bach.

Cancrizans.tape
DEFINE Bass() {
    JUMP(1==1, #D, 0)
    WRITE(48);>>
    WRITE(51);>>
    WRITE(55);>>
    WRITE(56);>>
    WRITE(47);>>>>

    JUMP(1==1, #D, 0)
    EMIT(READ(), 16, 0);>>
    EMIT(READ(), 16, 0);>>
    EMIT(READ(), 16, 0);>>
    EMIT(READ(), 16, 0);>>
    EMIT(READ(), 16, 0);>>
    EMIT(READ(), 8, 0)
    JUMP(1==1, #D, 2)
    EMIT(READ(), 16, 0);>>
}

DEFINE ScaleOne() {
    EMIT(READ(), 4, 1);v
    EMIT(READ(), 4, 1);>>
    EMIT(READ(), 4, 1);^
    EMIT(READ(), 4, 1);>>
    EMIT(READ(), 4, 1);<<
    EMIT(READ(), 4, 1);v
    EMIT(READ(), 4, 1);<<
    EMIT(READ(), 4, 1);
}

Claves del funcionamiento

  • Lectura y movimiento encadenados: EMIT(READ(), 4, 1);v emite el valor actual y desplaza el cabezal una fila hacia abajo en la misma línea.
  • Condiciones sobre la cinta: JUMP(READ()==74, #A, 2) utiliza el contenido de la memoria como lógica de control musical.
  • Polifonía multipista: SPAWN(1); SPAWN(0) habilita dos timbres simultáneos ejecutando voces independientes.
La idea clave de Cancrizans TAPE no necesita representar una partitura tradicional directamente. Puede representar la lógica espacial y temporal que genera la música.

15 Errores frecuentes

Error común Por qué ocurre y cómo evitarlo
Confundir SPAWN(1) con el cabezal SPAWN solo crea un canal de audio; el cabezal de lectura/escritura siempre es único y se mueve con <<, >>, ^, v.
Olvidar mover tras WRITE Dos WRITE seguidos sin movimiento sobrescriben la misma celda.
Confundir #A con A #A referencia la fila A en JUMP; A sin numeral es una variable.
Creer que >>>> mueve 4 celdas Cada >> es un paso; cuatro símbolos > equivalen a 2 pasos.
Salir de los límites Las filas válidas son A–D y las columnas 0–34.
Emitir en canal no inicializado Siempre ejecuta SPAWN(id) antes de llamar a EMIT(..., id).
Llamar funciones antes de definirlas Todo bloque DEFINE debe aparecer arriba de su invocación.

16 Referencia rápida

Memoria

Matriz de 4 filas (A–D) × 35 columnas (0–34). 0 = silencio, 1–127 = MIDI.

Osciladores (ID mod 4)

0: triangle · 1: sine · 2: square · 3: sawtooth.

SintaxisDescripción
WRITE(valor)Escribe un valor en la celda actual.
READ()Lee el valor de la celda actual.
SPAWN(id) / KILL(id)Crea o elimina un canal de emisión.
EMIT(valor, ticks, canal)Emite un evento sonoro (1 tick = 1 fusa).
JUMP(condicion, #fila, col)Salta a una posición si la condición es verdadera.
DEFINE nombre(...) { ... }Define una función reutilizable.
<< >> ^ vMueve el cabezal 1 celda (izquierda, derecha, arriba, abajo).
== != < > <= >=Operadores de comparación.
Resumen conceptual Escribe valores con WRITE, desplaza el cabezal con <<, >>, ^ y v, lee mediante READ, crea canales con SPAWN, produce sonido con EMIT y controla la posición mediante JUMP.
